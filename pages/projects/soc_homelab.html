02 Tech Stack
Splunk Enterprise
SIEM · Core Platform

Log ingestion from multi-source feeds, operational dashboards, correlation rules, and real-time alerting on IOCs.

Wazuh
EDR · Open Source

Endpoint Detection & Response agents on Windows targets. Behavioral detection correlated with Splunk alerts.

Atomic Red Team
Attack Simulation

Replays MITRE ATT&CK techniques (T1078, T1059…) to validate detection coverage and tune alert thresholds.

Metasploit
Exploitation Framework

Real exploitation runs against Metasploitable from an isolated Kali VM — verifying end-to-end detection chain.

MITRE ATT&CK
Threat Framework

Every Splunk alert is mapped to an ATT&CK technique. Coverage matrix tracked to measure defensive posture.

ML IDS
Custom Project Integration

Homemade intrusion detection model fed into Splunk — bridging this lab with the ML-IDS personal project.
